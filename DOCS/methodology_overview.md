# 方法论总览 · 把科学发现智能体用于医学

本项目沉淀了一套"可复用、可审计、诚实标注边界"的科研发现方法论。它不是某个
具体患者的方案，而是一组**可迁移到任意类似问题**的工具与流程。

## 核心思想
把 Hyra（腾讯混元递归自我改进科学发现）的范式迁移到两个新场景：
1. **时间序列 / 物理发现**（太阳黑子等）——官方评测器当尺子；
2. **医学机制发现**——把"患者已试过的干预"当评测器，反推"还没试的机制"。

共同纪律：**先量尺子再排序、防 reward hacking（测试集只最终报告 / 置换检验）、
区分内插与外推、硬门控守住红线**。

## 组件地图
| 组件 | 类型 | 作用 |
|---|---|---|
| `SKILLS/hyra-discovery` | 技能 | 本地、无外部 API 的科学发现 harness（10 个代理任务：医疗 SAR / 老药新用 / MOA / 合成药 / 多药联用 / 太阳黑子 / 数学定律 / 量子路由…）。大模型当算力，Python 仅做客观评分沙盒。 |
| `SKILLS/medical-discovery-loop` | 技能（模板） | 全领域机制扫描的持续流水线；**脱敏模板**，红线需自行填充。 |
| `SKILLS/trio-gvcf-cnv` | 技能 | 从 trio gVCF 读深度做全基因组 CNV 扫描 + 父母嵌合重查；纯 stdlib。 |
| `SKILLS/multiagent_lit_synthesis` | 技能 | "自家地基（权重化事实）+ 外部检索"多智能体综合范式，产出带目标罗盘的报告。 |
| `SKILLS/research-agent-landscape-analyzer` | 技能 | 分析科研智能体能否被调用/学习，生成结构化报告。 |
| `TOOLS/mechfit` | 框架 | 13 轴机制发现：岭回归+LOOCV+置换检验+硬门控。见其 README。 |
| `SOPS/*` | 文档 | VEP 解读、安全删除红线、机制发现 13 轴工作流。 |

## 诚实边界（务必传达）
- hyra-discovery 是**本地代理验收**，非腾讯 Hyra 官方同口径验收；太阳黑子/棋类为
  本地基线，不是官方赛制。
- mechfit 的排序在"已有实验无法区分候选"时会塌成 0，此时必须交外部证据。
- 任何医学输出都是**决策支持、非处方**，需临床/遗传医生裁决。
- 本套资产**不含任何真实患者隐私数据**：探针、报告、知识库均已脱敏为合成示例或模板。

## 如何开始
1. 想做科学发现闭环 → 读 `SKILLS/hyra-discovery/SKILL.md`，按需跑 dispatch。
2. 想从自己的干预史反推机制 → 把 `TOOLS/mechfit/probes.py` 换成你自己的数据，跑 `mechfit.py`。
3. 想做文献/证据综合 → 用 `SKILLS/multiagent_lit_synthesis`。
4. 有 trio 测序无 BAM → 用 `SKILLS/trio-gvcf-cnv`。
5. 解读 VEP / 批量删文件 / 写机制发现报告 → 查对应 `SOPS/`。
