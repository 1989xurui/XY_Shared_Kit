# SOP · 机制发现 13 轴工作流

把"已知干预结局"当作评测器反推"未试机制"的通用流程（mechfit 框架的底层方法）。
可直接套用到任何"从患者自身干预史发现下一步治疗"的场景。

## 1. 建立有符号机制轴（FEATURES）
- 每根轴是**有符号**的（+1 沿某方向推，-1 沿反方向拉回），不是 0/1 标志位。
- 理由：若把"降通量"另立新键，它在探针里采样数=0、权重不可辨识，模型只能给 0，
  等于把候选判死；而"降通量"生化上就是"升通量"的反方向，同根轴取负号即可继承信息。
- 典型 13 轴示例：mono_push / ox_flux / fuel_switch / recep_block / gut_source /
  iron_gate / iron_sub / a2_tone / nmda_mod / sedate / behav_only / leak_close / mtor_down。
  （用你自己的领域轴替换；轴的命名应反映机制方向，而非具体药。）

## 2. 编码探针（PROBES）—— 严守"编码纪律"
- 每条干预：名字、结局（POS/NULL/FAIL/WORSE）、各轴取值、判定终点、出处。
- **FEATURES 只按机制填，绝不参考 outcome 列**；outcome 只在拟合阶段读取。
- 任何特征若无法脱离结局独立论证，填 0。

## 3. 拟合与验证（mechfit.py 自动做）
1. **轴采样覆盖度**：列出每根轴被多少条探针踩到；采样数=0 的轴标记"从未采样"。
2. **岭回归 + LOOCV**：选正则强度使留一交叉验证 R² > 0（优于"恒预测均值"基线）。
3. **置换检验**：结局随机打乱 2000 次重拟合；若真实 R² 落在置换分布里 → 模型作废。
4. **权重 + 自助 CI**：不可辨识轴权重强制归零；报告 90% CI 是否跨 0。

## 4. 区分三类推断（防过度自信）
- **A 内插**：该轴在探针里采样过、且方向与候选一致 → 证据最强。
- **B 符号外推**：该轴只观测过相反方向，候选取其反 → 靠"线性可反推"假设，需标注。
- **C 轴外推**：该轴从未采样 → 权重为 0，分数不含其贡献，必须交外部证据。

## 5. 候选排序 + 硬门控
- 候选打分 = 乐观分（信线性外推）/ 保守分（只算真正内插过的证据）。
- 两者一分开若都压到 0 附近 → 说明已有实验无法区分候选，排序交外部证据 + 信息增益。
- **硬门控（HARD_VETO）**：任何撞红线的候选无论分数多高都不得进推荐位。

## 6. 信息增益排序
- 优先做"能首次点亮未采样轴"或"在稀疏采样轴上补信息"的实验，
  最大化减少不确定性，而非盲目试药。
