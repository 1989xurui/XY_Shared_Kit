# mechfit · 机制发现框架（脱敏通用版）

把"患者已经试过的干预"当作**评测器**，反推"还没试过的机制"该往哪走。
方法论从 Hyra 太阳黑子任务的 `srfit` 官方评测器迁移而来，已验证有效。

## 文件
- `probes.py` —— **你只需要改这一个文件**。里面 `PROBES` = 结局已知的干预（探针集），
  `CANDIDATES` = 待评机制。当前是**合成示例数据（SYNTHETIC-DEMO）**，仅演示方法。
- `mechfit.py` —— 拟合器 + 候选排序（岭回归 + LOOCV + 置换检验 + 自助置信区间 + 硬门控）。
  通用代码，无需改动。
- `plot.py` —— 把 `results.json` 画成三 panels 图（需 matplotlib）。
- `results.json` —— 运行后自动生成（当前为合成示例输出）。

## 运行
```bash
# 只需 numpy
python mechfit.py
# 画图（可选，需 matplotlib）
python plot.py
```
隔离 Python 示例（本项目用）：`C:\HY3\Hyra-results\.venv\Scripts\python.exe`

## 换成你自己的数据（关键纪律）
1. 打开 `probes.py`，把 `PROBES` / `CANDIDATES` 换成【你自己的】真实干预史。
2. **编码纪律（防循环论证）**：`FEATURES` 里每根轴只按药理学/生化机制填，
   **绝不参考 outcome 列**；outcome 只在拟合阶段读取。任何一条特征若无法脱离
   结局独立论证，填 0。
3. 结局编码：`POS=+1` / `NULL=0` / `FAIL=-1` / `WORSE=-2`。
4. 特征是有符号轴（+1 沿该方向推，-1 沿反方向拉回），不是 0/1 标志位——
   这样"降通量"能复用"升通量"在既有实验里继承的信息，而不是被偷偷补零判死。
5. `HARD_VETO` 换成【你自己的】红线裁决（某基因已判不解释病例等）。

## 它做什么（诚实边界）
- **先量尺子再排序**：模型必须先能复现 PROBES 的已知结局（LOOCV R² > 0 基线），
  才有资格排 CANDIDATES。
- **防 reward hacking**：置换检验把结局随机打乱 2000 次重拟合，若真实 R² 落在
  置换分布里，模型直接作废。
- **区分内插 / 符号外推 / 轴外推**：某轴采样数 = 0 的权重强制归零（不可辨识），
  绝不偷偷补零当"预测到了"；只列作"外推轴"，交外部证据。
- **硬门控**：撞红线的候选无论分数多高都不得进推荐位。

⚠ 这是决策支持工具，**不是处方**。所有排序必须交临床/遗传医生裁决。
